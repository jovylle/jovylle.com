A high-performance web tool that assists players with the **Desert Digging** feature in Sunflower Land.

🧠 **Key Technologies**:
- Vue 3 with Composition API
- Vite multi-page setup
- Tailwind CSS 4
- VueUse & Head API
- Puppeteer for screenshot automation
- API proxy with Vite dev server

📈 Used by **hundreds of players** daily
