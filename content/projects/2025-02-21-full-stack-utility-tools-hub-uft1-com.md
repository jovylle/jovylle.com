## Project Overview

"Wanabusful" (also branded as UFT1 Tools) is a personal passion project designed to provide a suite of simple, browser-based utilities. Built from scratch using Next.js, this full-stack application showcases my ability to integrate modern web technologies, handle real-time media processing, and deliver a user-friendly experience. The project is deployed locally for now, with plans for hosting on Vercel or a similar platform.

Key highlights include:
- A real-time audio delay tool that captures microphone input and plays it back with a user-selected delay, leveraging the Web Audio API.
- A clean, responsive UI styled with Tailwind CSS, ensuring accessibility across devices.
- Scalable architecture to easily add more tools in the future.

[Live Demo (TBD)](https://tools.uft1.com) | [GitHub Repository](https://github.com/jovylle/wanabusful)

## Challenges & Solutions

- **Real-Time Audio Processing**: Initially implemented with MediaRecorder, but switched to Web Audio API for live delay functionality. Overcame browser compatibility issues by ensuring proper cleanup of audio streams.
- **Responsive Design**: Used Tailwind’s utility-first approach to adapt layouts for mobile and desktop without custom media queries.
- **Dark Mode**: Laid the groundwork with CSS variables and a toggle component, ready for full implementation.

## Future Enhancements
