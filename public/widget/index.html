📖 Overview

The Jovylle Widget is a powerful, embeddable component that adds instant notification capabilities, AI chat assistance, and quick links to any website. Perfect for portfolios, web apps, and business sites.

🔔 Smart Notifications

Push alerts, messages, and updates to visitors. 4 types with auto-dismiss & persistence.

🤖 AI Assistant

GPT-4o-mini powered chat to answer questions about your portfolio & projects.

🎮 Live Leaderboard

Real-time game scores integrated directly in the widget.

🎨 Theme Support

Beautiful light & dark modes with automatic switching.

📱 Mobile Ready

Fully responsive design that works on all devices.

🔒 Style Isolation

Shadow DOM ensures zero conflicts with your site's CSS.

🚀 Installation

Add the widget to your website in seconds with a single script tag:

Basic Setup

<!-- Add this before closing </body> tag -->
<script 
  src="https://jovylle.com/widget/embed-inline.js"
  data-position="bottom-right"
  data-size="medium"
  async>
</script>

Configuration Options

Attribute Values Default Description
data-position bottom-right, bottom-left, top-right, top-left bottom-right Widget position on screen
data-size small, medium, large medium Widget dimensions
data-theme light, dark auto Color theme
data-density comfortable, compact comfortable Spacing/padding
data-open true, false false Open widget on page load
data-title Text string "Widget" Custom widget title in header
data-hide-chat true, false false Hide AI Chat tab
data-feedback-url URL string none Show feedback link with custom URL

✨ Features

Notification System

Host websites can use the widget as a notification center to display important messages to visitors.

  • 4 Types: Info (blue), Success (green), Warning (yellow), Error (red)
  • Smart Tab: Alerts tab auto-hides when empty
  • Badge Counter: Shows unread notification count
  • Persistence: Notifications saved to localStorage
  • Auto-dismiss: Optional 10-second auto-removal
  • Limit: Max 50 notifications with auto-cleanup

AI Chat Assistant

Powered by OpenAI's GPT-4o-mini model for intelligent conversations about your portfolio and projects.

  • Smart Context: Understands your skills, projects, and AI solutions
  • Quick Buttons: Pre-built conversation starters

  • Fast Responses: Low latency with better quality

Quick Links & Leaderboard

  • Portfolio Link: Direct access to your main site
  • Live Scores: Real-time reaction test leaderboard
  • Play Button: Quick access to the game

Basic Example

// Add a welcome notification
window.JovylleInlineWidget.addNotification({
  type: 'success',
  title: '👋 Welcome!',
  message: 'Thanks for visiting our site.',
  persistent: true  // Stays until user dismisses
});

// Temporary notification (auto-removes after 10s)
window.JovylleInlineWidget.addNotification({
  type: 'info',
  title: 'Quick Tip',
  message: 'Check out our new features!',
  persistent: false  // Auto-dismiss
});

💻 API Reference

addNotification(options)

Adds a new notification to the widget.

window.JovylleInlineWidget.addNotification({
  type: 'info',        // 'info' | 'success' | 'warning' | 'error'
  title: 'Hello!',     // Notification title (required)
  message: 'Welcome',  // Notification message (optional)
  persistent: true     // true = stays, false = auto-removes (default: true)
});
// Returns: notification ID (string)

removeNotification(id)

Removes a specific notification by ID or index.

const id = window.JovylleInlineWidget.addNotification({...});
window.JovylleInlineWidget.removeNotification(id);

clearAllNotifications()

Removes all notifications at once.

window.JovylleInlineWidget.clearAllNotifications();

getNotifications()

Returns an array of all current notifications.

const notifications = window.JovylleInlineWidget.getNotifications();
console.log(`You have ${notifications.length} notifications`);

Widget Controls

// Open widget
window.JovylleInlineWidget.open();

// Close widget
window.JovylleInlineWidget.close();

// Toggle widget
window.JovylleInlineWidget.toggle();

// Switch to specific tab
window.JovylleInlineWidget.switchTab('links');        // Quick Links
window.JovylleInlineWidget.switchTab('notifications'); // Alerts
window.JovylleInlineWidget.switchTab('chat');         // AI Chat

// Change theme
window.JovylleInlineWidget.setTheme('dark');  // or 'light'

// Get current state
const state = window.JovylleInlineWidget.state;
console.log(state.notifications.length);
